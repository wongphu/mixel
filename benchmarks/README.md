# Benchmarks

Reports from [`scripts/benchmark.sh`](../scripts/benchmark.sh), one file per Mac, named
after its chip, GPU cores and memory. Each has a readable results table and a JSON block for
compiling.

To add your Mac, run `scripts/benchmark.sh` and **email the report to
[mixelate@proton.me](mailto:mixelate@proton.me)**. See
[Benchmark your Mac](../README.md#benchmark-your-mac).
